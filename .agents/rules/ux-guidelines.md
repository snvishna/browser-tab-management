# UX Guidelines

1. **Prioritize Visual Excellence**: Implement designs that WOW the user and feel premium. Use curated, harmonious color palettes and sleek dark modes.
2. **Modern Aesthetics**: Utilize "Glassmorphism" (backdrop filters), deep shadows, and subtle gradients. 
3. **Typography**: Rely on modern sans-serif fonts (like Inter or Roboto) with clean hierarchies.
4. **Micro-animations**: Elements should respond to hover, click, and state changes with smooth, non-blocking CSS transitions to make the interface feel alive.
5. **Simplicity**: Do not overwhelm the user with too many commands at once. Default to sensible AI-driven defaults.
